# Employee_Data_Cleaning-SQL
 Employee dataset cleaning project using SQL Server, covering missing values, invalid phone numbers, duplicate emails, column transformation, and data-type correction.
 
 ## Project Overview
This project focuses on cleaning and transforming a messy employee dataset using Microsoft SQL Server. The dataset contained missing values, invalid phone numbers, duplicate email addresses, combined columns, and incorrect data types.

### Data Cleaning Performed
- Handled missing Values
- Fixed invalid phone numbers
- Remove duplicate email addresses
- combined Frist_Name & Last_Name
- Splite Department_Region AS different column Department and Region
